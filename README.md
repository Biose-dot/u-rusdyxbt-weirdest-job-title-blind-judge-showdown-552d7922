[Weirdest Job Title: Blind Judge Showdown](https://make.fun/c/u-rusdyxbt-weirdest-job-title-blind-judge-showdown-552d7922).

A real-sounding corporate title with one hilariously specific twist: the geese, and the need to apologize to them.

`main.py` (Python 3, standard library only) writes the entry to `/output/entry.txt`:

> Chief Apology Officer for Angry Geese

Run it locally with:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
